# Adding photos

1. Drop your photo in this folder, e.g. `photos/first-date.jpg` (2000px longest edge is plenty — bigger just slows down load on her phone).
2. In `../chapters.json`, point a chapter's `photos[].src` at `photos/first-date.jpg` and fill in `alt` with a short description.
3. Refresh the local dev server — no build step needed for v1.

Keep filenames lowercase, hyphenated, no spaces.
